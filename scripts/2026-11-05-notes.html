Au programme : des GIF animés dans ChatGPT, une preuve d'identité pour les assistants, les agents IA chez Uber, deux rachats dans le code et Apple qui calme ses dépenses.

ChatGPT crée des GIF animés

OpenAI permet de transformer un texte ou une photo en petite image animée, avec réglage de la vitesse et retouche image par image. C'est ouvert à tous les utilisateurs. Pour vous : idéal pour animer une capture d'écran dans un message de support.

  • The Decoder – ChatGPT can now turn text prompts and photos into animated GIFs

Prouver quel modèle a répondu

Anthropic présente un prototype qui vérifie, par cryptographie, quel modèle a écrit une réponse. C'est expérimental et limité aux textes courts. Pour vous : rien à essayer, mais une piste de confiance pour les entreprises.

  • The Decoder – Anthropic's new prototype proves which model wrote an AI response
  • TechCrunch – Anthropic is working on a system to prove AI models' identity

Les agents IA peinent à s'imposer chez Uber

Quatre personnes seulement ont réservé une course via un agent IA pendant la semaine la plus chargée d'octobre. Pour vous : testez les agents sur des tâches longues, pas sur celles qui prennent déjà une minute.

  • TechCrunch – Almost no one uses AI agents to book their Uber

OpenAI et Meta rachètent des sociétés de code

OpenAI rachète Pierre Computer Company pour adapter Git aux assistants de programmation, et Meta acquiert Conductor. Pour vous : plus de code produit vite, donc plus de vérification à prévoir.

  • The Decoder – OpenAI acquires Pierre Computer Company
  • TechCrunch – Meta acquires AI coding startup Conductor

Apple réduirait ses budgets IA internes

Selon la presse, Apple réduirait ses dépenses d'outils IA en interne ; ce n'est pas détaillé. Pour vous : notez ce qui vous fait vraiment gagner du temps.

  • TechCrunch – Apple is reportedly cutting budgets for its internal AI usage
